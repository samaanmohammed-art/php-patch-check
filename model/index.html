Is my model still available?

Type an OpenAI, Anthropic or Google Gemini API model ID and see the shutdown date and the replacement the provider names on its deprecation page. It runs in your browser and sends nothing.

As written in your code, for example gpt-4-turbo, o3-mini or claude-sonnet-4-5-20250929.

Data used

Data as of : rows copied from three pages. Providers change dates and add models; open the page for the current answer.

    What this page does not do

    This page accepts upper case and short forms; the scanner in the paid kit matches exact lower-case IDs only.

    It covers only the OpenAI, Anthropic and Google Gemini API deprecation pages. Amazon Bedrock, Google Cloud Vertex AI, Azure and other hosts set their own dates and use different IDs; they are not included. A model that is not in the data is not proof that it is still available. Nothing here is a guarantee or legal advice.
