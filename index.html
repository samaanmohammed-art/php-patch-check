Is my PHP version patched?

Type the PHP version number you see on your server. This page compares that number with the PHP security releases of 21 October 2026 and the end-of-life dates. It does not look at any website. It runs in your browser and sends nothing.

Example: 8.3.31. Find it with php -v or in your hosting panel.

What this page does not do

It only compares the number you type. Linux distribution packages (Ubuntu, Debian, Red Hat and others) can include a security fix without changing the version number, so a lower number does not always mean the fix is missing: check your distribution's security notice. After an update, the running PHP process (PHP-FPM, Apache) has to be restarted before it uses the new version. This is not security advice.

Does the version number tell the whole story?

Not always. Linux distribution packages (Debian, Ubuntu, RHEL and others) can include a fix without changing the version number, and the command-line php -v can differ from the PHP that serves your site (PHP-FPM must be restarted after an update). Check your distribution's security notice and your host's advice. This page is not security or legal advice.
