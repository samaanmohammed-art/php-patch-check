Is my runtime still supported?

Pick a product, type the version you run, and see its end-of-life date as published by endoflife.date. It does not look at any website or server. It runs in your browser and sends nothing.

Example: 8.2.29, 3.10.12, 22.11.0. Type at least the branch (8.2, 3.10, 22); the full number also shows whether a newer release exists.

    What this page does not do

    It only compares the number you type with the dates in the data. Linux distributions and hosting companies can keep supporting a version after the upstream end-of-life date, and some vendors sell extended support; check with whoever supplies your copy. This is not security advice.
