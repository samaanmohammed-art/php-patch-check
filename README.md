# Is my PHP version patched?

A single-file page: type a PHP version and see whether it is at or above the fixed releases of 21 Oct 2026 (8.5.12, 8.4.27, 8.3.36, 8.2.35) and when its branch ends. It only compares the number you type; it connects to nothing, scans nothing and does not patch or protect anything. Data: php.net release feed and endoflife.date, fetched 22 Oct 2026. Not security or legal advice.
